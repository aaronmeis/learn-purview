Altitude rule

Logical means which parts and how they talk. Components have responsibilities and interfaces; no regions, SKUs, or hostnames.

Logical components

Component Responsibility Realizes Inputs Outputs Source
Classification engine Detect sensitive info types with classifiers C1 Content, scan results Classifications [S1]
Information Protection Define and apply sensitivity labels and protection C2 Label policies, classifications Labeled or encrypted content [S1]
Data Loss Prevention Detect and act on sensitive data in use and in motion C2 DLP policies, classifications Alerts, blocks, activity events [S1], [S14]
Insider Risk Management Detect risky user activity from signals C4, C5 Activity signals, AI interactions Alerts, cases [S1], [S15]
Data Map Register sources, scan, extract metadata, classify, build lineage C1, C3 Registered sources, credentials Assets, classifications, lineage [S2]
Unified Catalog Search and curate assets from the Data Map C3 Data Map assets Curated catalog [S1], [S9]
Audit Record user and admin activity, including AI interactions, in the unified audit log C4, C5 Activity events Searchable audit records [S1], [S16]
eDiscovery Search, hold, review, and export content as evidence C4 Mailboxes, sites, Teams, AI interactions Cases, holds, exports [S1], [S18]
Compliance Manager Assess posture against regulations C4 Assessments, improvement actions Compliance score [S1], [S25]
DSPM / DSPM for AI Front door: discover AI use, recommend and apply policies, assess oversharing C5 AI interactions, SharePoint data, other solutions' signals Reports, one-click policies, risk assessments [S15], [S16]

Logical data model

Entity Key attributes Relationships Source
Sensitivity label name, protection settings applied to content items; published by label policy [S1]
Sensitive information type pattern or classifier detected in content items and assets [S1]

Asset qualified name, schema, classifications, lineage belongs to a data source; appears in catalog [S2]

AI interaction prompt, response, app, agent, referenced files produces audit record; retained by retention policy [S16], [S18]
Case type (eDiscovery, IRM), holds, review sets collects content and interactions [S18]

Design decisions at this level

  • The multicloud connector returns metadata and classification only to Purview, not content [S9].
  • Prompts and responses for Copilot in Fabric and Security Copilot are not captured without a collection policy; only the audit events are [S15].
