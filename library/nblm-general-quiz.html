Q1. An architect is designing a data governance strategy for a US federal agency operating strictly within Azure Government. Why does the requirement to scan Amazon S3 buckets for sensitive information types (SITs) present a fundamental physical architecture conflict?

Type: multiple choice

  • The multicloud scanning connector for Amazon S3 is currently not supported in the Azure Government cloud environment. [correct]
  • Why: Physical view documentation explicitly identifies the Amazon S3 connector as an exclusion in Azure Government, requiring either a commercial account workaround or accepting a visibility gap.
  • Azure Government requires the use of self-hosted integration runtimes (SHIR) for all external cloud providers, which S3 does not support.
  • Encryption keys stored in AWS KMS cannot be decrypted by the Purview service when initiated from a government-tenant boundary.
  • The mandatory use of Azure Private Link in government clouds prevents the 'Role ARN' authentication method from reaching AWS IAM endpoints.
  • Hint: Consider the specific feature availability matrix provided for US Government customers regarding multicloud connectors.

Q2. To ensure that custom-built generative AI applications provide full visibility within the Data Security Posture Management (DSPM) for AI Activity Explorer, which of the following configuration steps are required?

Type: multiple select

  • Developing the application to interface with the Microsoft Purview APIs in Microsoft Graph. [correct]
  • Why: The Purview SDK and Graph APIs are the primary mechanism for bringing prompts and responses from custom (non-Copilot) apps into the Purview governance boundary.
  • Creating a Microsoft Purview 'Know Your Data' (KYD) policy for the specific application. [correct]
  • Why: A KYD policy is necessary to authorize the collection, analysis, and display of interaction data within the DSPM for AI reports.
  • Enabling the 'storing prompts and responses' setting within the Purview portal for the application. [correct]
  • Why: Without explicitly turning on prompt and response storage, the system may only log the event metadata without the actual content needed for deep risk analysis.
  • Deploying a self-hosted integration runtime (SHIR) on the server hosting the custom AI model.
  • Hint: Focus on the 'Policies for Data discovery' and SDK requirements for non-Microsoft AI services.

Q3. When an organization needs to perform forensic investigations on AI interactions within Copilot for Fabric or Security Copilot, they must implement a specific ___ to capture the actual text of prompts and responses, as these are not logged by default.

Type: fill in the blank

  • Answer: collection policy (also accepted: Purview collection policy, data collection policy)
  • Why: Standard audit logs for these specific services only capture metadata; a collection policy is the mandatory logical component required to store the actual interaction content for eDiscovery.
  • Hint: This logical control bridges the gap between simple event logging and full content retention for legal review.

Q4. A data steward is attempting to register a Snowflake source in the Purview Data Map using a key pair for authentication. Why is it recommended to use the Azure CLI rather than the Microsoft Purview portal to store the private key?

Type: multiple choice

  • The Purview portal interface has a known issue where it corrupts multi-line PEM formatting during the save process. [correct]
  • Why: Technical integration notes for Snowflake explicitly warn that the portal's handling of multi-line strings can invalidate PEM keys, making CLI-based secret management more reliable.
  • The portal does not support the RSA key pair (PKCS#8) standard required by Snowflake's security architecture.
  • Keys uploaded via the portal are not automatically backed by Azure Key Vault, creating a security compliance violation.
  • The portal limits private key size to 1024 bits, which is insufficient for Snowflake's minimum 2048-bit requirement.
  • Hint: Look for specific implementation warnings regarding multi-line PEM strings in the integration view.
