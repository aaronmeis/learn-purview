# Front Back Review
1 What is the primary overarching purpose of Microsoft Purview as a platform? To govern, protect, and manage organizational data wherever it resides.
2 Name the five top-level outcome capabilities defined in Microsoft Purview's conceptual architecture. Know your data, protect sensitive data, govern data, manage risk and regulation, and secure AI use.
3 Which solution family within Microsoft Purview encompasses Information Protection, DLP, Insider Risk Management, and DSPM? The Data Security solution family.
4 What solutions are included in the Microsoft Purview Data Governance solution family? Data Map and Unified Catalog.
5 What solutions constitute the Data Compliance solution family in Microsoft Purview? Audit, eDiscovery, Compliance Manager, Data Lifecycle Management, Communication Compliance, and Records Management.
6 In Microsoft Purview's logical architecture, what is the primary responsibility of the Classification Engine? To detect sensitive information types within content using predefined or trainable classifiers.
7 What is the main operational output of Microsoft Purview Information Protection? Content that has sensitivity labels or persistent encryption applied to it.
8 What data entity is emitted by an AI interaction with Microsoft Copilot or a custom agent? An audit record (recorded under CopilotInteraction in the unified audit log).
9 What type of data is returned to Microsoft Purview when scanning an AWS S3 bucket? Technical metadata and classification findings only (no file content is returned).
10 What mechanism allows Microsoft Purview's Data Map to securely access Amazon S3 buckets across clouds? An AWS IAM role with a trust relationship configured using a Microsoft Account ID and External ID.
