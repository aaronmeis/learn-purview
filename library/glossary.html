GLOSSARY — Microsoft Purview

Terms earned during the day.

Term Definition View Block
Sensitivity label A persistent marking on content that can carry protection (encryption, watermark, access restriction) and is published by a label policy Conceptual, Logical 2, 3
Sensitive information type (SIT) A pattern or classifier used to detect a specific category of sensitive data in content or assets Conceptual, Logical 2, 3
Classification The act of detecting SITs with classifiers against content or assets Conceptual 2
Data Map The component that registers data sources, scans them, extracts metadata, classifies, and builds lineage Logical, Physical 3, 4
Unified Catalog The searchable, curated catalog built from Data Map assets Logical 3
Data source A registered connection (type, endpoint, collection) that the Data Map scans; contains assets Logical 3
Asset A cataloged object (qualified name, schema, classifications, lineage) belonging to a data source Logical 3
Policy A rule (DLP, retention, insider risk, or collection type) that targets locations and uses SITs/labels to decide an action Logical 3
DSPM (Data Security Posture Management) The solution that assesses data-security risk and recommends/applies policies across the estate Conceptual, Logical 2, 3
DSPM for AI DSPM's front door for AI: discovers AI use, recommends one-click policies, and runs a weekly oversharing risk assessment (e.g. top 100 SharePoint sites by usage) Logical, Integration/AI 3, 5
Insider Risk Management (IRM) Detects risky user activity from behavioral/activity signals, including AI interactions, and raises alerts/cases Logical 3
Compliance Manager Assesses organizational posture against named regulations and produces a compliance score Logical 3
Audit (unified audit log) Microsoft 365's system of record for user and admin activity, including AI interactions Logical, Physical 3, 4
eDiscovery Search, hold, review, and export content (including AI interactions) as legal/investigative evidence Logical 3
AI interaction A prompt-and-response pair between a user or agent and an AI app; produces an audit record Logical, Integration/AI 3, 5
Case A container (eDiscovery or IRM type) that collects holds, review sets, and interactions Logical 3
Integration runtime (IR) The compute that performs a Data Map scan; comes in four flavors: Azure IR (Microsoft-managed, public endpoints), AWS IR (Microsoft-hosted, for S3/RDS), Managed VNet IR (private endpoints), and self-hosted IR (SHIR, customer VM or Kubernetes) Logical, Physical 3, 4
Self-hosted integration runtime (SHIR) Customer-run compute (JDK 11) that scans sources Purview's managed runtimes can't reach directly, e.g. on-prem databases Physical 4
Managed VNet IR An Azure-managed integration runtime that scans through private endpoints instead of public ones Physical 4
Information protection scanner A Windows service (config in SQL Server) that discovers, classifies, labels, and protects content on on-prem file shares and SharePoint Server, and enforces on-prem DLP Physical 4
Data management landing zone Microsoft's recommended Azure Cloud Adoption Framework pattern: one dedicated Azure subscription per Entra tenant hosting the Purview account Physical 4
Collection (Purview) A container used to organize sources/assets and scope role-based access within a Purview account Physical 4
Key pair authentication RSA (PKCS#8) credential pair used for Snowflake connections, replacing basic auth (which Snowflake is retiring) Physical, Integration/AI 4, 5
Role ARN / external ID The AWS IAM mechanism Purview's AWS-hosted IR assumes to scan S3 — a cross-account role trust with an external ID, not a stored access key Physical, Integration/AI 4, 5
Connected app (Salesforce) The OAuth mechanism Purview uses to authenticate to Salesforce's REST API for metadata scanning Physical, Integration/AI 4, 5
Collection policy (AI) A Purview policy that captures full prompt/response text for Fabric Copilot, Security Copilot, and non-Copilot AI apps; without it, only audit events (no text) are captured Integration/AI 5
CopilotInteraction The specific unified-audit-log record type emitted for a Copilot prompt/response event Logical, Integration/AI 3, 5
Agent (Purview context) A non-human actor (Copilot Studio, Foundry, etc.) that reads/writes data on a user's behalf and inherits its parent app's protections rather than getting its own Conceptual, Integration/AI 2, 5
Microsoft Entra Agent ID The directory entry type that gives non-human AI agents (from Copilot Studio, Foundry) an identity Purview and other tools can govern Integration/AI 5
Multicloud scanning connector The Data Map connector family (S3, Snowflake, Salesforce, etc.) that returns metadata and classification only — never source content — back to Purview Logical, Physical 3, 4
GCC / GCC High / DoD Microsoft's three US-government Microsoft 365 cloud tiers, each with its own feature-parity gaps versus the commercial baseline; DoD tenants pair with Entra ID in Azure Government Physical 4
FedRAMP Equivalency Microsoft's practice of demonstrating a higher FedRAMP Impact Level (e.g. High) via completed audit evidence (SARs) even where the formal Agency ATO instrument is a lower level (e.g. Moderate) — the resolution to the GCC "Moderate vs. High" apparent conflict Physical 4
Private Link (Azure) The network-isolation mechanism used to keep the Purview account off the public internet Physical 4
Data Security Investigations A newer Purview solution that uses generative AI to help security teams analyze and respond to data breaches and risky-insider incidents Logical, Integration/AI 3, 5

Term Definition Category Source
Microsoft Sentinel The SIEM next to Purview. It hosts the OneTrust partner solution that feeds findings into DSPM, and can ingest Purview audit and alert data. Neighbors & platform [S27]
Microsoft Defender for Endpoint Endpoint security product whose device onboarding Purview shares: onboarded devices are what Endpoint DLP and third-party AI site visibility run on. Neighbors & platform [S19, S22]
Microsoft Entra ID The identity service Purview relies on for sign-in, roles, and Conditional Access. GCC High and DoD tenants pair with Entra ID in Azure Government. Neighbors & platform [S8, S23]
Copilot Studio Microsoft's maker platform for custom agents. Its agents inherit protections and their interactions are audited, retained, and discoverable in Purview. Neighbors & platform [S18, S17]
Microsoft Foundry Microsoft's platform for building enterprise AI apps and agents. Foundry agents are covered by Purview's agent protections and appear in Entra Agent ID. Neighbors & platform [S17, S22]
Microsoft 365 Copilot The Microsoft 365 AI assistant. Purview supplies its DLP, labels, auditing, retention, and risk detection; it grounds on data the user can already open. Neighbors & platform [S16]
SharePoint Online Microsoft 365 content service and Purview's main first-party target: labels, auto-labeling, DLP, eDiscovery, audit, and DSPM for AI's weekly oversharing assessment. Neighbors & platform [S5, S15]
OneTrust Third-party privacy platform whose sensitive-data findings reach Purview DSPM through a Microsoft Sentinel partner solution (preview). Government cloud support is UNVERIFIED. Neighbors & platform [S27, S26]
OneLake Microsoft Fabric's single data lake. Microsoft's landing-zone guidance makes it the convergence layer for governed data that applications reach through approved paths. Neighbors & platform [S24]
Fabric mirroring Fabric feature that replicates operational data (for example SAP or Oracle) into OneLake in near real time, instead of apps querying those systems directly. Neighbors & platform [S24]
Azure Government Microsoft's isolated US government Azure cloud. Its Purview Data Map excludes Amazon S3, Amazon RDS, commercial Power BI, preview sources, and Synapse lineage. Gov cloud & compliance [S4, S8]
FedRAMP P-ATO The formal FedRAMP authorization instrument for a cloud service. GCC's P-ATO is FedRAMP Moderate (from DHHS); separately, Microsoft completed FedRAMP High audits and claims High equivalency. Gov cloud & compliance [S35]
Agency ATO An authorization to operate issued by a specific federal agency. GCC High holds agency ATOs at both FedRAMP Moderate and High (DHS, DoJ, FBI, Treasury). Gov cloud & compliance [S35]
Security Assessment Report (SAR) The audit evidence from a FedRAMP assessment. Microsoft's completed High-level SARs for GCC are the basis for its FedRAMP High equivalency claim. Gov cloud & compliance [S35]
DoD Impact Level 4 and 5 (IL4/IL5) DoD security levels for controlled unclassified and mission data. Microsoft's sources list both GCC High and DoD as meeting IL4 and IL5. Gov cloud & compliance [S8]
CJIS FBI Criminal Justice Information Services security policy. Listed among GCC's compliance posture claims. Gov cloud & compliance [S5, S8]
IRS 1075 IRS Publication 1075 safeguards for federal tax information. Listed among GCC's compliance posture claims. Gov cloud & compliance [S5, S8]
DFARS 7012 DFARS 252.204-7012, the defense clause for safeguarding covered defense information. Listed for GCC High and DoD. Gov cloud & compliance [S8]
NIST SP 800-171 NIST controls for protecting controlled unclassified information in nonfederal systems. Listed for GCC High and DoD. Gov cloud & compliance [S8]
ITAR US export controls on defense articles and data. Listed for GCC High and DoD. Gov cloud & compliance [S8]
Commercial baseline The commercial (enterprise) Purview feature set. Government deployment guides list only differences from it, so a blank cell usually means parity. Gov cloud & compliance [S7]
Azure integration runtime (Azure IR) The default, Microsoft-managed scan compute for sources with publicly reachable endpoints. Nothing to install; it runs in the source's region when Purview can detect it. Runtime & network [S3]
AWS integration runtime (AWS IR) Fully managed scan compute that Microsoft hosts in its own AWS account, used for Amazon S3 and RDS. Runtime & network [S3, S9]
Kubernetes self-hosted integration runtime A self-hosted runtime on the customer's Kubernetes cluster for on-prem or virtual-network sources. Scales with the job; updates are manual today. Runtime & network [S3]
Managed VNet IR hibernation A Managed VNet integration runtime with no scans for more than 90 days hibernates. The first Test Connection fails and asks you to retry in 15 minutes; a direct scan waits up to 15 extra minutes (Queued_Waking Up IR). Runtime & network [S3]
Private endpoint A private IP interface into a service over Azure Private Link. Used to keep the Purview account and its portal off the public internet, and by Managed VNet IR to reach sources. Runtime & network [S23, S3]
Azure Key Vault Where Purview scan credentials live: passwords, client secrets, and private keys referenced by Purview credentials. Runtime & network [S10, S11]
Role-based access control (RBAC) in Purview Purview roles (for example Data Reader, Data Source Admin) assigned to Entra groups and scoped by collection, with least privilege. Runtime & network [S23]
Conditional Access Entra ID policy that enforces requirements such as MFA; Microsoft recommends it for privileged Purview roles. Runtime & network [S23]
AWS IAM role (for S3 scanning) An AWS role that trusts Microsoft's account ID with an external ID; the AWS IR assumes it to read S3. No access key is stored. Runtime & network [S9]
kms:Decrypt The AWS KMS permission the scanning role needs for buckets encrypted with customer-managed keys. Without it, those buckets fail to scan. Runtime & network [S9]
AWS Service Control Policy (SCP) An AWS Organizations guardrail that can silently block the scanner. It must allow AssumeRole, GetBucketLocation, GetObject, ListBucket, GetBucketPublicAccessBlock, and region us-east-1. Runtime & network [S9]
SMB The Windows file-sharing protocol the information protection scanner uses to reach on-prem shares. Runtime & network [S12]
NFS The Unix/Linux file-sharing protocol; scanner support is in preview. Runtime & network [S12]
UNC path A \server\share path. How scanner content-scan jobs name the on-prem repositories to scan. Runtime & network [S12, S14]
Lineage How data moves between assets, captured by the Data Map (for Snowflake, static lineage). Shown in the catalog. Purview features [S2, S10]
Qualified name An asset's unique identifier in the Data Map, built from the source's endpoint and object path. Purview features [S2, S10]
Label policy Publishes sensitivity labels to users and groups and sets defaults; labels do nothing until a label policy publishes them. Purview features [S1]
Auto-labeling Applies sensitivity labels automatically when content matches sensitive information types or trainable classifiers. Available across commercial and US government clouds. Purview features [S1, S5]
Trainable classifier A classifier trained on example content to recognize a category (such as contracts or source code) where a fixed pattern would not work. Purview features [S1]
Named-entity SIT Sensitive information types that detect names, addresses, and similar entities. Not yet at parity in government clouds (in development or backlog). Purview features [S5, S6, S7]
Retention policy Keeps or deletes content after a set time. For AI, the Data Lifecycle Management location is Microsoft Copilot Experiences. Purview features [S18]
Data Lifecycle Management The Purview solution for retention and deletion of content, including AI interactions. Purview features [S1, S18]
Legal hold Preserves content in place inside an eDiscovery case so it cannot be permanently deleted while the matter is open. Purview features [S1]
Review set The eDiscovery (Premium) container where collected items, including AI interactions, are analyzed, tagged, and exported. Purview features [S1, S18]
Activity explorer Shows activity on labeled and sensitive content; in DSPM for AI it is where AI interactions, including Copilot Studio chat text, are reviewed. Purview features [S15, S21]
Data explorer Shared view of where classified and labeled content sits across locations, used across Purview solutions. Purview features [S1]
Compliance score Compliance Manager's measure of posture against assessed regulations, raised by completing improvement actions. Purview features [S1, S25]
Improvement action A recommended control task in Compliance Manager; completing it raises the compliance score. Purview features [S1]
Adaptive Protection Links Insider Risk user risk levels to DLP: higher-risk users are blocked, lower-risk users are warned or audited, for example when pasting into AI sites. Purview features [S28]
Purview browser extension Browser add-on on onboarded devices that lets DLP and Insider Risk see sensitive data going to third-party AI sites. Purview features [S19]
Browse-to-URL policy A DSPM for AI policy about visits to AI sites. It cannot be created in GCC High or DoD, where only supported AI sites are available. Purview features [S7]
Know Your Data policy The DSPM for AI policy that brings a custom AI app's prompts and responses (sent through the Purview SDK and Graph APIs) under governance. Purview features [S20]
ItemClass The item property eDiscovery uses to find AI interactions, for example IPM.SkypeTeams.Message.Copilot.Studio.* for Copilot Studio agents. Purview features [S18]
Oversharing Data reachable by more people, or AI, than intended, usually from broad permissions plus missing labels. DSPM for AI assesses it; it does not fix ACLs. Purview features [S15]
Grounding data The organizational content (SharePoint, OneDrive, Teams) an AI app retrieves to answer a prompt. Labels, DLP, and access checks decide what reaches the response. Purview features [S16, S15]
TOGAF ADM The Open Group's Architecture Development Method. Here: conceptual view in Phases A-B, logical in Phase C, physical in Phases D-E, plus governance for AI. Frameworks views
DoDAF The DoD Architecture Framework. Its viewpoints (OV, CV, SV, DIV, StdV) organize the four Purview views. Frameworks views
OV-1 DoDAF high-level operational concept graphic: the one-picture conceptual view of people, agents, external stores, AI apps, and regulators. Frameworks views
SV-1 DoDAF systems interface description: components and their interfaces, used for the logical view and, with named systems, the physical view. Frameworks views
