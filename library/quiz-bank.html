Quiz bank — Microsoft Purview

Retrieval items for blocks 6-8.

Conceptual / logical

  1. Which logical component realizes capability C1, and what physical service realizes it?
  2. Name three external systems and the mechanism each uses.
  3. Which control stops an AI feature from grounding on data the user cannot open?
  4. Name the five capabilities Microsoft states as Purview's outcomes, and one actor for each.
  5. What's the difference between "Know your data" (C1) and "Govern data" (C3) — which components serve each?
  6. In the ERD, what does SENSITIVITY_LABEL's N—N relationship to CONTENT_ITEM tell you about how labels are modeled?
  7. Which entity emits AUDIT_RECORD, and what's the cardinality of that relationship? Why does that matter operationally?
  8. Trace the logical flow from a scanned data source to an investigation case — name every intermediate stage.

Physical / deployment

  1. Name the four "clouds" in the physical deployment topology and one thing that runs in each.
  2. Where does the Purview account itself physically live — M365 tenant or Azure subscription? What does Microsoft recommend around it?
  3. What OS, sizing, and database does the information protection scanner require?
  4. Which two data sources are explicitly excluded from the Data Map in Azure Government? Which cloud's Power BI is the exception?
  5. True or false, and cite the source: GCC and GCC High have conflicting FedRAMP levels documented by Microsoft.
  6. What licensing trap catches people scanning on-prem file shares with DLP?
  7. Which integration runtime would you choose to scan Amazon S3, and who operates it?

Integration and third-party

  1. What auth mechanism does the Amazon S3 connector use, and what's the one thing it explicitly does NOT return to Purview?
  2. Why is Snowflake migrating away from basic auth, and what should replace it? Name the one operational gotcha with how you store the replacement credential.
  3. What's the key difference between what the Snowflake connector classifies vs. what the Salesforce connector classifies?
  4. How does OneTrust data reach Purview DSPM — directly, or through an intermediary? Name the intermediary and its deployment status.
  5. Which external system integration is marked UNVERIFIED for gov-cloud support, and why?
  6. List two AWS-side failure modes for S3 scanning and their fixes.

AI elements

  1. What does DSPM for AI actually do that the semantic index alone doesn't?
  2. Where does a Copilot Studio agent's actual chat transcript get stored, and which tool retrieves it for review?
  3. What's the difference between an audit event and a captured prompt/response for Fabric or Security Copilot? What turns the latter on?
  4. Name two AI agent platforms explicitly NOT supported by Purview's agent protections.
  5. In the AI data path diagram, what happens between "grounding data" and "response" — name the control and describe what it checks.
  6. How does eDiscovery search AI interactions specifically? Give the ItemClass pattern.

Framework / synthesis

  1. Place the Data Map in a TOGAF ADM phase and a DoDAF viewpoint. Justify both.
  2. Name one design decision that only makes sense once you've seen the physical view (i.e., invisible at the logical altitude).
  3. If you had to redesign this system for a customer that also has an on-prem SQL Server data warehouse, which physical component would you add, and where does it run?
