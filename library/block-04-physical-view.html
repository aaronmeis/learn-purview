Retrieval check

Question

Which physical service realizes that component, and what changes in a government cloud?

Answer cues

All solutions (admin) is realized by Microsoft Purview portal: one entry to governance, security, and compliance solutions, running in Microsoft cloud (SaaS). Government-cloud differences: see the cloud/tenant variants table in Physical View — don't assume parity.

Exit criteria

  • Every logical component maps to a physical realization or is marked as a gap.
