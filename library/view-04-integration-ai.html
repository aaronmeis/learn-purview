  • GCC High and DoD tenants pair with Entra ID in Azure Government [S8].

  • Agents: Microsoft Entra Agent ID gives a directory of agent identities from Copilot Studio and Foundry [S22].

Integration risks

Risk Where Mitigation Source
S3 scanning unavailable Azure Government Data Map Scan S3 from a commercial Purview account, or accept the gap; design decision for block 8 [S4]
KMS-encrypted buckets fail to scan AWS Add KMS Decrypt to the IAM role [S9]
Bucket policy or SCP blocks the scanner AWS Allow AssumeRole, GetBucketLocation, GetObject, ListBucket, GetBucketPublicAccessBlock, and us-east-1 [S9]
Snowflake basic auth retired Snowflake Move to key pair; store the private key with Azure CLI, not the portal (the portal corrupts multi-line PEM) [S10]
Deleted source objects linger in the catalog Snowflake, Salesforce Periodic catalog cleanup [S10], [S11]
Copilot prompt text missing from investigations Fabric / Security Copilot Turn on the collection policy [S15]
OneTrust path is preview and gov support unknown OneTrust Treat as UNVERIFIED until Microsoft documents it [S26], [S27]
