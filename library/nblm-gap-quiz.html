  • Snowflake requires the private key to be uploaded as a binary file (Certificate) rather than a secret string.
  • Hint: Consider how different user interfaces handle 'hidden' characters like newlines.

Q6. In the context of the AI data path, if a user prompt is grounded in data from a SharePoint site, explain how Microsoft Purview ensures that a sensitivity label like 'Highly Confidential' prevents data leakage through the AI response.

Type: short answer

  • Model answer: When a Copilot or agent initiates the grounding process, it identifies the sensitivity labels of the referenced files.
